# SONARA

### Your Music. Your World.

A personal music app for Android — search, stream and play songs, artists,
albums and playlists, with queue management, playlists, favorites, recently
played, lyrics, background playback and offline downloads.

</div>

---

## About

SONARA is a private, personal app. It is not published on any store and is
distributed only as a sideloaded APK from this repository's releases.

## Build

Requires JDK 17 and the Android SDK.

```sh
./gradlew assembleProdRelease   # release (signed only with a local keystore.properties)
./gradlew assembleDevDebug      # dev debug APK (applicationId com.sonara.dev)
```
